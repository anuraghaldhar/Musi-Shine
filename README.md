## What's new in MusiShine 2.0.0
First public release of MusiShine, a free, fast and mobile-first music streaming app.

### 🎵 Playback
- Smooth music streaming, designed for mobile
- Clean player with play, pause, next and previous controls
- Recently played history

### 🔐 Login & Sync
- Sign in with Google (Firebase Authentication)
- Likes, playlists and recently played sync across devices via Firestore
- No phone number or card needed

### 🎨 UI
- Cute glowing music-note mascot and animated loading screen
- Mobile-first, responsive layout
- Fast load times

### 📲 Install
- Install as PWA from your browser, or
- Download the APK from the [Releases](../../releases) page

### 🔧 Under the hood
- Built with plain HTML, CSS and JavaScript
- Firebase (Spark plan) for auth and database
- No ads, no subscription

## Download
1. Go to **Releases**
2. Download `Musi_Shine_v2_0_0.apk`
3. Allow "Install unknown apps" on your phone, then install
